# Аванс по договору — отчёт на дату

CLI на Python для расчёта выплат по договорам и работам.

## Запуск

Требуется Python 3.11+. Внешние пакеты не нужны.

```bash
python src/main.py --data data --date 2026-11-10
```

Для CSV:

```bash
python src/main.py --data data --date 2026-11-10 --output report
```

Создаются `report/works_report.csv` и `report/contracts_report.csv`.

## Правила

- Только `paid` с `paid_at <= report_date` считаются выплаченными.
- `queued` и `refunded` не считаются выплаченными.
- Платёж с `work_id` относится к этой работе.
- Платёж без `work_id` распределяется внутри договора по правилам `DECISIONS.md`.
- Деньги считаются через `Decimal`.
